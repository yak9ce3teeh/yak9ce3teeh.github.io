# YakBot project link

This directory links the personal website repository to the separate YakBot project.

- [YakBot repository](https://github.com/yak9ce3teeh/yakbot)
- [QQ bot resources and local setup](https://github.com/yak9ce3teeh/yakbot/tree/main/bots/qq)

The YakBot repository is private. Sign in with an account that has access to open these links. It contains the platform-specific source and character resources; this public directory contains links only.

This is a README link directory, not a Git submodule or an operating-system symlink. GitHub Pages cannot fetch private submodules. The website's YakBot service entry remains a Coming soon placeholder until a service website is available.
